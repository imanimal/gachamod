# Translations

gachamod ships in English, Simplified Chinese (`zh-CN`), Spanish (`es`, Latin American), Brazilian Portuguese
(`pt-BR`) and Russian (`ru`). The code is in `src/lib/i18n`. English text is the key: `t("View mods")` looks the
words up in `zh-CN.json` and the others, and shows the English when a line has no translation yet.

The language follows Windows unless it's picked in Settings, Appearance, Language. Picking one reloads the window, so
text built when a module loads is right too.

## Writing code

- Every piece of text a person reads goes through one of these:
  - `t("Turned off {n} mods", { n })`: a line. Placeholders are `{name}`, filled from the object.
  - `tn(n, "{n} mod", "{n} mods")`: a line that changes with a count. The plural form is the key.
  - `tx("Press {key} in game", { key: <Kbd>F7</Kbd> })`: placeholders that are elements. Text inside the element
    gets its own `t()`.
- The first argument is always a plain `"..."` string literal, never a template literal or a variable, so
  `scripts/i18n.mjs` can find it. Build changing parts with placeholders, never by joining strings: word order
  differs between languages.
- Whole sentences, not fragments glued together. `t("Delete {name}?")`, not `t("Delete") + " " + name + "?"`.
- Don't translate: mod, creator and character names from GameBanana, file names, paths, key names (F7, Ctrl),
  product names (gachamod, XXMI Launcher, GameBanana, 3DMigoto, GIMI and the other importers), log lines,
  telemetry, settings keys, and prompts sent to the chatbot.
- Game names do get translated (Chinese players know Genshin as 原神), so show them through `t()` too.
- Messages from the backend arrive in English. `errorText(e)` and `toast()` translate them by the patterns in
  `backend.ts`. Code that decides something by a message's words uses `errorEnglish(e)` or `english(text)`, never
  the shown text.
- A new user-facing message in Rust gets its pattern in `backend.ts`.

## Checking

`node scripts/i18n.mjs` counts the translated lines per language and fails when a translation's `{names}` don't
match its key. `--missing ru` writes the untranslated keys to `i18n-missing-ru.json`, with where each is used.

## Translating

- Same voice as the English: plain, short, a normal desktop app. No marketing words, no exclamation marks.
- Keep every `{name}` exactly as written. Move it wherever the sentence needs it.
- A plural line is an object with the language's forms: Russian `{ "one", "few", "many", "other" }`, Spanish and
  Portuguese `{ "one", "other" }` (Spanish also `"many"` for large round numbers, which can repeat `"other"`), and
  Chinese a plain string.
- Use the words each game's own translation uses for its things (Agents in Zenless, Resonators in Wuthering Waves).
- Labels stay short: German-length text breaks buttons, and Russian runs about 30% longer than English. Prefer the
  shorter of two right words.
- `docs/i18n/glossary.md` has the words each language uses for gachamod's things and the game names. Use them, and
  add a line when you pick a word for something new.
